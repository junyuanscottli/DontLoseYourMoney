# 价值投资哲学研究

沉淀一套自洽的价值投资方法论：财富、内在价值、护城河、安全边际这些概念到底在说什么，以及如何把它们用到具体标的分析上。

## 现状

- `canon-00-purchasing-power-as-wealth.md`：把「财富」重新定义为个人购买力在整个经济体资源调用中所占的**份额**，而非货币的名义数量；由此重新解释内在价值——衡量一家公司是否具备 power over customers，以及这种 power 能否传导给股东。
- `canon-02-power-and-moats.md`：借 Emerson 的依赖-权力理论，把「护城河」从品牌/网络效应/规模效应等表面名词，还原为**依赖不对称**的结构，并给出如何衡量、预测这种权力的具体方法（反事实退出测试、自我强化性、替代函数、合法性来源）。

两篇笔记搬自个人研究库的「价投真经」系列（原 00、02 篇），保留原编号以便后续追加。

## 开放问题

- 「价投真经」系列还有 01、03 篇以及一篇「价值陷阱」尚未迁移——是否要整体搬过来，还是只挑对方需要的部分？
- 这套「依赖不对称 → 股东权力」的框架目前是纯理论，还没有对着具体标的走过一遍——找什么样的公司做第一个试跑案例？
- 内在价值的判断高度依赖对 power 的定性判断，如何降低这一步的主观性/如何交叉验证？
