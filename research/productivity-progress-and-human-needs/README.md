# 人类生产力进步与持久需求相关的思考

研究人类社会生产力的进步轨迹及其驱动力，并进一步追问：在技术、制度与组织形式持续变化的背后，是否存在长期没有显著改变的核心人类需求。

## 现状

路线刚开启。研究将结合 AI 交互、书籍、YouTube 与其他媒体材料，区分历史事实、来源观点、AI 综合和个人判断，最终形成一份有证据链的整体报告。

## 开放问题

- 人类社会的生产力经历了哪些关键阶段和跃迁？
- 能源、技术、制度、资本、知识、分工、人口与需求分别发挥了什么作用？
- 哪些人类需求在不同生产力阶段保持稳定？这些需求在各个阶段分别以什么形式出现？
- AI 是新的生产力跃迁，还是既有趋势的延续？
