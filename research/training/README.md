# 培训

两个人正式开工前的自我培训，目的是**对齐思想和知识底座**——后面所有路线的讨论都建立在这层共识上。这条路线不直接产生收入，但决定了其他路线的判断质量。

三块内容：

1. **三大表 + 美国证券市场基础** —— 共同的财务语言和市场常识
2. **价投真经** —— 价值投资的方法论
3. **以往投资案例** —— 从真实案例里提炼判断框架
