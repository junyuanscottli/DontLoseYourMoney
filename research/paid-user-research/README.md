# 美国付费用户调研

研究美国市场上付费用户调研（用户访谈、焦点小组、产品测试、日记研究、专业人士访谈等）里的收益机会。见过单次报酬达数百美元量级的活动，远高于常规兼职时薪。

钱从哪来：企业的产品 / 市场研究预算。公司为了接触到特定画像的用户（某类软件的决策者、特定职业、特定消费习惯），通过招募平台或调研公司支付参与激励。单价高低主要取决于**画像有多稀缺**，而不是花多少时间。

所谓「套利」，核心是：找到我们**如实具备**、但在市场上稀缺的画像，把时间以远高于机会成本的价格卖出去。

**边界：** 只研究如实符合筛选条件的参与。虚报筛选问卷、一人多号、违反 NDA 等做法违反平台条款，不在本路线研究范围内，也不写进本仓库（见 AGENTS.md 第 7 节）。

## 现状

刚开启，尚无沉淀。

## 开放问题

- 高单价活动到底集中在哪些画像？是否主要是 B2B 专业人士（IT / 软件决策者、医生、金融从业者），普通消费者能拿到的上限在哪？
- 真实的**有效时薪**是多少？要把找活动、填筛选问卷、被拒、准备、参与、等付款的时间全部算进去，而不是只看单次标价。
- 这是一次性的小额收入，还是能做成稳定的现金流？单个平台对同一人的参与频率有没有限制？
- 我们两人的背景（学历、专业、在用的工具与产品、消费习惯）能匹配哪些稀缺画像？
- 身份与报税：参与激励算什么性质的收入、如何申报、我们各自的身份是否对参与有限制？
- 这个方向的上限是不是就是「高薪零工」？有没有更上游的机会（比如反过来做招募 / 撮合方）？
