# 美国付费用户调研

研究美国市场上付费用户调研（用户访谈、焦点小组、产品测试、日记研究、专业人士访谈等）里的收益机会。见过单次报酬达数百美元量级的活动，远高于常规兼职时薪。

钱从哪来：企业的产品 / 市场研究预算。公司为了接触到特定画像的用户（某类软件的决策者、特定职业、特定消费习惯），通过招募平台或调研公司支付参与激励。单价高低主要取决于**画像有多稀缺**，而不是花多少时间。

所谓「套利」，核心是：找到我们**如实具备**、但在市场上稀缺的画像，把时间以远高于机会成本的价格卖出去。

**边界：** 只研究如实符合筛选条件的参与。虚报筛选问卷、一人多号、违反 NDA 等做法违反平台条款，不在本路线研究范围内，也不写进本仓库（见 AGENTS.md 第 7 节）。

## 现状

T-003（税务与身份）、T-004（风险识别）已有初稿，结论摘要如下。详见 [compliance-risk-analysis.md](compliance-risk-analysis.md)，可直接执行的步骤见 [participant-playbook.md](participant-playbook.md)。

- **税务是成本项，不是门槛。** 激励不论形式都是应税收入。系统化地做，默认按 Schedule C + 自雇税处理，留税约 25–35%。2026 年起 1099-NEC/MISC 门槛提到 $2,000，多数收入不会有 1099，要靠自己记账。→ [incentive-tax-rules.md](incentive-tax-rules.md)
- **身份是真正的门槛。** 官方对「付费研究参与者算不算就业」没有口径，各校说法矛盾。非公民、非绿卡的人在美国境内做有偿调研处在灰区，做 expert network 基本等于未授权就业。人在境外完成风险明显降低。→ [immigration-status-rules.md](immigration-status-rules.md)
- **如实参与的主要损失是做了拿不到钱。** 付款认定由研究方单方面决定，请款和争议时限 30 天到 6 个月不等。容易无意踩线的有：资料过时、AI 润色、VPN、出境测试、共用 PayPal。→ [platform-terms.md](platform-terms.md)
- **线下焦点小组有天花板。** 筛选常排除过去 6 个月参加过的人，高频收入更可能来自线上 UX 平台和 expert network。Expert network 的主要约束来自现任雇主。
- **诈骗判别规则**：钱的方向一反（要你付钱，或先给钱再让你转出）就是诈骗；正规平台不在聊天工具里谈付款。→ [scam-patterns.md](scam-patterns.md)

## 开放问题

- 高单价活动到底集中在哪些画像？是否主要是 B2B 专业人士（IT / 软件决策者、医生、金融从业者），普通消费者能拿到的上限在哪？
- 真实的**有效时薪**是多少？要把找活动、填筛选问卷、被拒、准备、参与、等付款的时间全部算进去，而不是只看单次标价。
- 这是一次性的小额收入，还是能做成稳定的现金流？（平台本身不限频率，但单个研究的筛选会限，线下焦点小组尤其明显，见 T-004 结论）
- 我们两人的背景（学历、专业、在用的工具与产品、消费习惯）能匹配哪些稀缺画像？
- 我们两人各自落在身份风险矩阵的哪一格？能做 / 不能做 / 只能境外做？（身份细节不进仓库，只写结论）
- 这个方向的上限是不是就是「高薪零工」？有没有更上游的机会（比如反过来做招募 / 撮合方）？
